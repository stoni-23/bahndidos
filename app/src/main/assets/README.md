# Assets (leer)

Nur Ordnerstruktur — keine Designs / keine Spielidee.

| Ordner | Zweck (Platzhalter) |
|--------|---------------------|
| `bg/` | Hintergründe / Parallax |
| `player/` | Spieler-Sprites |
| `enemies/` | Gegner |
| `items/` | Pickups / Items |
| `ui/` | HUD / Buttons / Icons |
| `fx/` | Effekte (Explosion, Thrust, …) |
| `sfx/` | Sound-Effekte (falls als Asset) |
| `music/` | Musik (falls als Asset) |
| `fonts/` | Schriftarten |
| `menu/` | Menü-Grafiken |

Zusätzlich: `res/drawable/`, `res/drawable-nodpi/`, `res/raw/sfx/`, `res/raw/music/`.

Dateien hier ablegen wenn Content kommt. Bis dahin nur `.gitkeep`.
